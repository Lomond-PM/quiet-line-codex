# Quiet Line for Codex 维护规范 / Maintenance policy

开发、移植和打包时遵守[引擎维护规范](plugins/quiet-line/engine/AGENTS.md)。这也适用于 Codex 插件自身的技能、工具说明、返回文本、插件文案及提供给 Agent 的指南。

修改绘画引擎时，保留现有创作指导。不得顺带新增或强化影响 Agent 创作策略、审美偏好或笔触选择的内置指导。确有必要修改模型可见 Prompt 时，单独列出位置、变更前后的原文、理由和预期影响，获得用户明确同意后再应用。技术约束应准确表述为可验证的事实。

Follow the [engine maintenance policy](plugins/quiet-line/engine/AGENTS.md) for development, ports, and packaging. It also applies to Codex-specific skills, tool descriptions and results, plugin copy, and guides supplied to the agent.

Preserve existing creative guidance when changing the painting engine. Engine work must never add or strengthen incidental model-visible guidance that influences an agent's creative strategy, aesthetic preferences, or stroke choices. When a prompt change is necessary, list each location, the exact before and after text, the reason, and the expected impact separately. Apply it after explicit user acceptance. Keep technical constraints accurate and verifiable.
